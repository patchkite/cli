# Changelog

All notable changes to `@patchkite/cli` are documented here. This project follows [Semantic Versioning](https://semver.org/).

## 1.0.0

First public release.

- Account, app, deployment, collaborator, and access key management.
- `release`, `release-react` (with Hermes), and `release-flutter` (Android), with code signing.
- `patch`, `promote`, and `rollback`; `binary add` for patches from store builds.
- `debug` to stream SDK logs from a device; `admin` commands for user management and storage cleanup.
